## Method

Same as [`../PROCESS.md`](../PROCESS.md) Part 1: average rank, report min / max / population std, no interpolated missing teams.

`RankDelta` = Sep 1 consensus rank minus this rank (positive = climbed since 9-1). `JuneRank` retained from the June 17-list baseline.

Files: `sources/*.csv`, `source_ranks.csv`, `source_sb_odds.csv`, `consensus_power_rankings.csv`, generated by `average_ranks.py`.
