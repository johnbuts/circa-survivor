## Method

Same as [`../PROCESS.md`](../PROCESS.md) Part 1: average rank, report min / max / population std, no interpolated missing teams.

`RankDelta` = Sep 9 consensus rank minus this rank (positive = climbed since 9-9). `JuneRank` and `Sep1Rank` retained.

Files: `sources/*.csv`, `source_ranks.csv`, `consensus_power_rankings.csv`, generated by `average_ranks.py`.

## DraftKings odds (The Odds API)

Raw audit JSON: `odds_api_dk.json`. After Week 1 the API board is **upcoming games only** (16 Week 2 events on Sep 15), not the 240-event full-season dump from Sep 9. `build_matchup_implied_odds.py` reads that file.

Unfilled cells are games The Odds API did not return. Do not invent later-week prices. This dump is Week 2 only, so the join is exact `(away, home)` — reverse-pair fallback would stamp Week 2 prices onto later rematches.

Spot-checks (moneyline implied %, vig not removed) are Week 2 games in this run.
