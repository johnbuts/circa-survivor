# Week 1 2026 consensus — sources

Window: **latest full 1–32 per outlet** from training camp / preseason through Sep 1, 2026. One list per outlet. Average uses **15** independent lists. April–June draft/Garrett lists are not mixed in.

Each source’s 1–32 order is stored under `sources/` (`sources/manifest.csv` plus one `{id}.csv` per outlet). Super Bowl prices quoted on a ranking page are on that source file and in `source_sb_odds.csv`. DraftKings per-game moneylines/spreads/implied % are in `game_implied_odds.csv`.

## Dropped

- TSN / ESPN UK — same ESPN panel article
- Yahoo Sports Sportsnaut reprint — not the Frank Schwab countdown
- Yardbarker — NFL Spin Zone reprint
- CBS Super Bowl **tiers** (Sep 1) — not a 1–32 order
- B/R NFL 1000 after roster cuts — top 10 talent grades, not 1–32 power rankings
- FOX Vacchiano fetch — incomplete numbered headings
- PFN “most to play for in preseason” — not a 1–32 power list
- SI Betting preseason Week 2 / Week 3 editions — older SI lists; only the post-preseason edition is used
- Any April–June PROCESS.md URL that was not this outlet’s latest camp/preseason list

## Method

Same as [`../PROCESS.md`](../PROCESS.md) Part 1: average rank, report min / max / population std, no interpolated missing teams. B/R ranks 32 (Dolphins) and 29 (Jets) are unnumbered sections on the page between numbered neighbors, not guessed-missing teams. `RankDelta` = June 17-list consensus rank minus this rank (positive = climbed).

Files: `sources/*.csv`, `source_ranks.csv`, `source_sb_odds.csv`, `consensus_power_rankings.csv`, generated by `average_ranks.py`.

## DraftKings scrape

Live DK sportsbook JSON (`eventgroups/88808` and sportscontent league endpoints) returned **403** from this host. The 272-game board in `draftkings_raw_scrape.txt` is the existing full-season 2026 copy-paste (Wed Sep 9 opener through Week 18), written into this folder so the June parent files stay untouched. It is not a new browser dump from Sep 1. Re-paste the DK NFL board here if you want prices from today.

Per-game lines (spread, moneyline, implied %) are in `game_implied_odds.csv`. The Team × week grid is `team_weekly_implied_odds.csv`.
